FFMPEG - makes the game's videos small enough for the phone

PUT THIS FILE IN THIS FOLDER:

    ffmpeg.exe

Where to get it: https://www.gyan.dev/ffmpeg/builds/ - "ffmpeg-release-essentials.zip" (tested with 9.0.2).
In the zip, ffmpeg.exe is in the "bin" folder.
Or install it with this command, then this folder can stay empty (the companion finds it on the PATH):
    winget install Gyan.FFmpeg.Essentials

Not needed (leave them or delete them): ffprobe.exe, ffplay.exe and everything else in the download.

It is right when this file exists (or ffmpeg is installed and on the PATH):
    ...\ue4ss\Mods\TownfallCompanion\tools\ffmpeg\ffmpeg.exe

The videos also need radvideo64.exe (see the radtools folder).
Without ffmpeg.exe and radvideo64.exe the phone shows no game videos.
